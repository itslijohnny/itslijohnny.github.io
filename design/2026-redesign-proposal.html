A blog that looks like the work it’s about.

Your posts are notebooks: parsers, classifiers, pipelines, plots. So the site should read like an instrument, not a card grid. This proposal keeps Hugo and keeps Stack’s bones, and replaces the surface with a quiet, dense, typographically-driven index built on 2026 platform CSS — no webfonts, no jQuery, no framework.

The three calls everything else follows from

Direction

Borrow the instrument

The palette is sampled from viridis — matplotlib’s default colormap, and something you have literally shipped in your own figures. Teal carries interaction, violet carries structure, and the yellow end is spent in exactly one place: what’s new.

Rules, not cards

Twelve posts on a card grid is twelve boxes of chrome around eight words of information. Hairline rules, a fixed date column and mono metadata let the whole archive be scanned in one screen without a single shadow.

Ship no fonts

Three system stacks — a grotesque for headlines, a text serif for reading, mono for anything measured. Nothing to download, no layout shift, and CJK falls back to the reader’s own system face instead of a 4 MB subset.

Data Analysis with Docker

Data analysis is not all about reports or visualization. Correctness and reproducibility matter just as much, and a consistent environment is what makes reproducibility possible. There are several ways to get one — I found that Docker lets me repeat an experiment in the same environment at any time, and scale it out when the data grows.

The image is based on Ubuntu and ships the usual tools: Jupyter Notebook with both a Python 3 and an R kernel, so R Magic can run both languages inside one .ipynb.

# build once, mount your notebooks, work anywhere
docker build -t jl/notebook .
docker run -p 8888:8888 -v "$PWD:/home/jovyan/work" jl/notebook

Trend, translated into a decision

What makes it 2026 and not 2021

“On trend” is worth nothing as a mood board, so here is each one as a mechanism you can actually merge.

2026 direction → what it means here → how it ships
TrendThe decision on your siteMechanism
Quiet, content-first UI Cards, shadows and hover-lifts come off the index. Hierarchy is carried by type size, a fixed date column and hairline rules. Override Stack’s article-list partial; delete the card shadow tokens
Perceptual color One accent, interpolated and mixed perceptually so hover and tint states stay in-family in both themes. oklch() tokens, color-mix(in oklab, …)
Component-level responsive The index rows, cover figure and TOC rail respond to the space they’re in, so the same partial works in the feed, in a related-posts strip and on a phone. container-type: inline-size, @container, cqi units
Native page transitions Index → post animates the title into place instead of a white flash. Progressive: browsers without it just navigate. @view-transition { navigation: auto }, view-transition-name
Scroll effects without JS Reading progress and the TOC’s active section are CSS-driven, so there is no scroll handler on the main thread. animation-timeline: scroll(), view()
Command-palette navigation Search becomes ⌘K over titles, tags and categories — a dialog, not a separate /search page. <dialog> + popover, Hugo-generated JSON index, ~2 KB of JS
Typography as the payload Zero font requests. Real hierarchy from three system stacks, plus proper text-wrapping and hanging punctuation. text-wrap: balance / pretty, hanging-punctuation, font-variant-numeric
Designed dark mode Both themes are token sets; the toggle keeps working and OS preference is the default. Cover images get a slight dark-mode dim rather than glaring. light-dark(), color-scheme, :root[data-theme]
Honest data marks The tag cloud goes. Topics become a ranked bar list with real counts — the same charting standards you’d apply in a notebook. New topics widget partial over .Site.Taxonomies
Machine readers are readers Agents and models now quote sites the way search engines used to link them. Full-text RSS stays, plus a clean text mirror and per-post structured data. llms.txt, JSON feed, Article JSON-LD replacing the hand-rolled block
Aging content, marked A 2019 post says so, quietly, above the fold. Nothing looks more dated than a stale post pretending to be current. Date-diff in the article partial → margin note

Subtraction first

What I’d delete from the repo

Half the redesign is removal. These are all in your tree today, loaded on every page.

jquery 1.11.0 + morphext Loaded from a Google CDN on every page to rotate three words on one page. Replace with a 15-line CSS keyframe cycle, or cut the effect.
static/webfonts/fa-* Six formats of Font Awesome for two icons on the About page. Stack already inlines SVG icons from assets/icons — add two SVGs and drop the folder.
scss/all.min.css + animate.css A whole second stylesheet from the old Hexo theme, cascading against Stack’s. This is where the unpredictable spacing comes from.
<style> inside shortcodes about-brief.html ships hardcoded #FF4C60 and pixel margins per render. Moves into the token layer so it themes correctly in dark mode.
mermaid 8.2.3 from unpkg Six years old and fetched at runtime. Render diagrams at build time, or pin a current version locally.
The tag cloud widget Font-size-as-quantity is the least accurate encoding available, and with 12 posts it’s noise. Replaced by the ranked topic bars.

Sequenced so the site is never broken mid-way

How I’d build it

  1. Pin the theme, then stop fighting it

    The hugo-theme-stack submodule isn’t checked out in this working copy, so exact partial paths need confirming against your pinned v4.0.3 tag. Everything below lives in your repo as overrides — the submodule stays untouched and upgradable.

  2. Token layer

    One custom.scss defining the palette, type stacks and spacing scale as custom properties for both themes. Nothing visual changes yet — but every later step reads from here instead of hardcoding.

  3. Delete the legacy layer

    Remove the jQuery/Morphext/Font Awesome/all.min.css block from head/custom.html and rewrite the About shortcodes against the tokens. This alone drops several hundred KB and three third-party requests.

  4. Rebuild the index

    Override the article-list partial into the lead-plus-ruled-index layout, add the topic-bars widget, retire the tag cloud.

  5. Rebuild the article

    Serif measure, margin rail, TOC as a sticky mono list, CSS reading progress, staleness note, code blocks restyled from the token palette.

  6. Motion & search last

    View transitions between index and post, then the ⌘K palette over a Hugo-generated JSON index. Both are additive — if either is cut, the site still works.

  7. Check the numbers, not the vibes

    Lighthouse and a byte count before/after, contrast audit on both themes, and a pass with reduced motion and keyboard only.
